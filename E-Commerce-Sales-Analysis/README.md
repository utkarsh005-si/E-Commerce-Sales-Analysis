# E-Commerce Sales Analysis

## Project Overview
This project analyzes e-commerce sales data to understand sales performance, profitability, product categories, customer trends, and regional performance.

## Tools Used
- Python: Data cleaning and exploratory analysis
- MySQL: SQL queries and business analysis
- Power BI: Interactive dashboard and data visualization

## Dataset
- 800 cleaned records
- 13 columns covering orders, products, customers, sales, and profit
- Analysis period: January to September 2026

## Work Completed
- Removed duplicate records and handled missing values.
- Imported cleaned data into MySQL.
- Analyzed sales, profit, categories, states, customers, payment methods, and monthly trends using SQL and Python.
- Created a two-page Power BI dashboard with KPI cards and sales analysis charts.

## Key Findings
- Total Sales: ₹3,218,196.35
- Total Profit: ₹661,473.95
- Cleaned Records: 800
- Highest-sales category: Furniture
- Highest-sales month: March
