# E-Commerce Sales Analysis

An end-to-end data analytics project using Python, MySQL, and Power BI to clean, analyze, and visualize e-commerce sales data.

## Project Overview
This project analyzes e-commerce transactions to identify sales trends, top-performing product categories, state-wise performance, and customer payment preferences.

## Tools & Technologies
- **Python:** Pandas, data cleaning, exploratory data analysis, and visualizations
- **MySQL:** Data storage, SQL queries, aggregations, and business analysis
- **Power BI:** Interactive dashboards and sales performance reporting
- **Excel/CSV:** Dataset handling

## Dataset
- Raw dataset: `data/ecommerce_sales_raw.csv`
- Cleaned dataset: `data/ecommerce_sales_cleaned.csv`
- Cleaned records: **800**

## Key Findings
- **Total Sales:** ₹32,18,196.35
- **Total Profit:** ₹6,61,473.95
- **Records Analyzed:** 800
- **Top Sales Category:** Furniture
- **Highest-Sales State:** Maharashtra
- **Highest-Sales Month:** March

## Project Structure
- `data/` — Raw and cleaned datasets
- `python/sales_analysis.py` — Python data cleaning and analysis
- `sql/sales_analysis.sql` — SQL analysis queries
- `dashboard_page1.png` — Power BI dashboard page 1
- `dashboard_page2.png` — Power BI dashboard page 2
- `E-Commerce Sales Analysis- Professional.pbix` — Power BI report

## Dashboard
The Power BI report includes sales and profit KPIs, category-wise sales, state-wise performance, monthly sales trends, payment modes, city-wise sales, and product performance.

## How to Use
1. Download or clone this repository.
2. Run the Python script using Python with Pandas and Matplotlib installed.
3. Import the cleaned CSV into MySQL to execute the SQL queries.
4. Open the `.pbix` file in Power BI Desktop to explore the dashboards.

## Note
This project uses a practice dataset for learning and portfolio purposes.
